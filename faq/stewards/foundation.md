# Can a manufacturer set up a foundation that acts as an open-source software steward for community-led projects?

Yes, a manufacturer can set up a foundation that acts as an _open-source software steward_ for community-led projects. The Commission's guidance says foundations _"regularly financed by manufacturers"_, or that let manufacturers contribute regularly, _"are to be considered stewards"_ of the projects they support on a sustained basis ([[CRA Recital 19]], [[CRA-GUIDANCE point 78]]); how a project is financed does not affect whether it is placed on the market ([[CRA Recital 18]], [[CRA-GUIDANCE point 64]]). The guidance does not address a foundation controlled by a single manufacturer.

A manufacturer doesn't need a separate foundation to be a steward, though. The guidance says a company can be the manufacturer of the software it sells and at the same time the steward of open source software it publishes without selling, even the free "community" version of the same project: it _"is deemed a steward to the free (or community) version, and a manufacturer to the monetised version"_ ([[CRA Article 3(14)]], [[CRA-GUIDANCE point 73]], [[CRA-GUIDANCE point 76]]). The role is decided per piece of software, by whether it is monetised ([[CRA-GUIDANCE point 74]]).

For more on how the two roles interact, see [[manufacturers/both-manufacturer-and-steward]].
