# Can a manufacturer set up a foundation that acts as an open-source software steward for community-led projects?

Yes, a manufacturer can set up a foundation that acts as an _open-source software steward_ for community-led projects. The Commission's guidance says foundations _"regularly financed by manufacturers"_, or that let manufacturers contribute regularly, _"are to be considered stewards"_ of the projects they support on a sustained basis ([[CRA Recital 19]], [[CRA-GUIDANCE point 78]]); how a project is financed does not affect whether it is placed on the market ([[CRA Recital 18]], [[CRA-GUIDANCE point 64]]).

A manufacturer doesn't need a separate foundation to be a steward, though. A company can be the manufacturer of the software it monetises and at the same time the steward of open source software it publishes without monetising it, even the free "community" version of the same project ([[CRA Article 3(14)]], [[CRA-GUIDANCE point 76]]); the role is decided per piece of software ([[CRA-GUIDANCE point 74]]). See [[manufacturers/both-manufacturer-and-steward]].
