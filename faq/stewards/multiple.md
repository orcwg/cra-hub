# Can a project have multiple stewards?

Yes, a project can have more than one open-source software steward: nothing in the CRA prevents it. Neither the CRA nor the Commission's guidance addresses the case, so what follows is the hub's reading.

The guidance looks at each organisation and each project separately: a company or foundation (a _legal person_) is the steward of each project it publishes and supports on a sustained basis without monetising it ([[CRA Article 3(14)]], [[CRA-GUIDANCE point 72]], [[CRA-GUIDANCE point 74]]). Two organisations that both do so for the same project are both its stewards.

Few projects are in that position, though. The guidance ties the steward role to the organisation that publishes the project: _"responsibility lies with those who publish and control the FOSS"_ ([[CRA-GUIDANCE point 49]], [[CRA-GUIDANCE point 71]]). A company that started a project and still contributes to it once a foundation publishes it is a contributor, not a second steward: in the guidance's examples the foundation is the only steward and the contributing companies have no obligations ([[CRA Recital 18]], [[CRA-GUIDANCE Example 28]]). See [[stewards/foundation]].

Where two stewards do exist, each has to put in place its own cybersecurity policy for the project ([[CRA Article 24]]; see [[stewards/obligations]]). Two policies for one project are harder to run than one, so a single steward with clear responsibility is usually more practical.
