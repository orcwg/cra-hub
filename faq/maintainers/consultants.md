# Do common consulting arrangements make me a manufacturer?

No. Consulting work such as helping a client install, configure or integrate software is a service, not a product. Services are not covered by the CRA, so a consultant is not a manufacturer, even when the work is about open source software ([[CRA-GUIDANCE point 59]], [[CRA-GUIDANCE Example 19]]). The one exception is a consultant who substantially modifies the software as part of the service, which can make them its manufacturer ([[CRA-GUIDANCE point 59]], [[CRA Article 22]]).

This also holds for consulting around a project you publish yourself. Selling implementation, integration, training or other professional services for your own open source software does not, by itself, make you its manufacturer, as long as the software can be downloaded, installed and updated freely and your services are optional ([[CRA-GUIDANCE point 55]], [[CRA-GUIDANCE point 56]], [[CRA-GUIDANCE Example 18]]). What would make you a manufacturer is selling access to the software itself: a paid edition, or a version whose updates, maintenance or technical assistance only paying customers get. That version is a product you sell, and you have the manufacturer's obligations for it ([[CRA-GUIDANCE point 57]], [[CRA-GUIDANCE Example 17]]).

Those obligations apply only to the version you sell. For a free version of the same project, you have the obligations of an open-source software steward if you are a company or foundation (a legal person, see [[legislation/legal-person]]) that provides sustained support for its development. If you are an individual (a natural person), the free version falls outside the CRA entirely ([[CRA-GUIDANCE point 52]], [[CRA-GUIDANCE point 53]]).
