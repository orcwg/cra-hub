# Am I subject to the CRA if I earn a living from the open source project I maintain?

Not as long as what you earn from the project only covers your actual costs, which include a reasonable salary or [living expenses][] ([[CRA Recital 15]], [[CRA-GUIDANCE point 58]], [[CRA-GUIDANCE point 61]]). See [[cra-itself/actual-costs]] for what counts.

Beyond that, it depends on how you earn it:

- **Donations**: accepting donations with the intention of making a profit is a commercial activity ([[CRA Recital 15]]). Donations fluctuate, so a degree of flexibility applies, and a project supported only through donations is unlikely to be considered placed on the market; donations that are really the price of access are a sale ([[CRA-GUIDANCE point 61]], [[CRA-GUIDANCE point 62]]). See [[maintainers/donations]].
- **Paid services around freely available software**, such as consulting, training, integration or optional support: these are services, not a sale of the software, as long as anyone can download, install and update it without paying ([[CRA-GUIDANCE point 56]], [[CRA-GUIDANCE Example 18]]). See [[maintainers/consultants]] and [[maintainers/technical-support]].
- **Sponsorship, grants or paid development** of features that you then release to everyone: how the development was financed does not count ([[CRA Recital 18]], [[CRA-GUIDANCE point 63]], [[CRA-GUIDANCE point 65]]).
- **Selling the software itself**: if you charge for the software or for a paid edition, you are selling a product and you are its manufacturer, with the obligations of [[CRA Article 13]] ([[CRA-GUIDANCE point 51]], [[CRA-GUIDANCE point 57]]). Support, updates or maintenance that only paying users get count the same way, except that for an individual a price that only recovers actual costs, including living expenses, does not ([[CRA-GUIDANCE point 58]]).

Even when you sell a version, your manufacturer obligations apply only to that version. If you offer both a paid "enterprise" version and a free "community" version, you are the manufacturer of the enterprise version only ([[CRA-GUIDANCE point 52]]). The community version stays outside the CRA if you are an individual; if you are a company or foundation, you are its open-source software steward instead ([[CRA-GUIDANCE point 53]], see [[maintainers/solo-maintainer-steward]]).

See [[cra-itself/monetisation]] for the other forms monetisation can take, such as monetising other services through the software or requiring users' personal data.
