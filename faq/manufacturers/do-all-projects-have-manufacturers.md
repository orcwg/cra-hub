# Does every open source project have to have a manufacturer?

No. Not every open source project has a manufacturer, and the CRA does not require one to be identified.

A project has a manufacturer only when whoever publishes it supplies it in the course of a commercial activity, which for open source usually means monetising it. The Commission's guidance says that whether the CRA applies to an open source project _"depends solely on whether the natural or legal person that publishes it places it on the market"_ ([[CRA-GUIDANCE point 87]]), and the CRA says that supplying open source software _"not monetised by their manufacturers"_ is not a commercial activity ([[CRA Recital 18]]). Most open source projects are not monetised by the people who publish them, so they are outside the CRA's scope and have no manufacturer ([[CRA-GUIDANCE point 65]], [[CRA-GUIDANCE Example 27]]).

Nor does every project have an open-source software steward: a steward must be a legal person, such as a company or foundation, that supports the project on a sustained basis ([[CRA Article 3(14)]]). A project maintained by an individual or an informal community has neither ([[CRA-GUIDANCE Example 34]]).

See [[manufacturers/what-is-a-manufacturer]] and [[manufacturers/multiple-manufacturers]] for when a project does have a manufacturer, and [[stewards/do-all-projects-have-stewards]] for stewards.
